### S-1-13 — 소셜 로그인(OAuth Provider) 설정

원본 노트 요약: 구글 로그인 코드 구현 완료 — `signInWithGoogleAction`(origin 동적 처리), `GoogleSignInButton.tsx`, `/auth/callback` 재사용. PM이 Google Cloud Console OAuth 클라이언트/Supabase 설정 완료. e2e는 배선(버튼→Supabase OAuth authorize)만 검증, 실 구글 계정 로그인은 자동화 제외. 최종 결정: 이메일(인증 없이 즉시)+구글 로그인 병행, "Confirm email" 비활성화로 SMTP 없이 운영. e2e 13개 파일 48/48 통과 재확인 완료.

→ 남은 것은 **프로덕션에서 실제 구글 계정으로 끝까지 로그인되는지** 검증뿐. 2차 개발의 **마지막 TASK**로 배치(PM 지정) — 2차 다른 작업에 선행 의존성 없음.

**2026-08-07 완료**: 실사용 검증 중 `redirect_uri_mismatch`(400) 발견 — Google Cloud Console OAuth 클라이언트("payLens")의 "승인된 리디렉션 URI"에 우리 앱 콜백(`https://payfocus.vercel.app/auth/callback`)이 등록돼 있었음. 실제로는 Google→**Supabase(GoTrue)**→우리 앱 순으로 리다이렉트되므로 Google에는 Supabase의 콜백 주소(`https://mzeokhamkbzdqpfcbpwh.supabase.co/auth/v1/callback`)가 등록돼야 함 — PM이 값을 교체 후 재시도해 정상 로그인 확인, S-1-13 최종 완료.
