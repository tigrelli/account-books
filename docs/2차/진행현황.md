# 진행 현황 (Progress Tracker) — 2차 개발

> 이 파일은 `docs/2차/WBS.md`의 TASK 목록을 체크리스트로 옮긴 것입니다. **TASK 하나가 완료되면 PM 확인 후 이 파일의 해당 체크박스만 `[ ]` → `[x]`로 바꿉니다.** `WBS.md` 자체(설계 문서)는 수정하지 않습니다 — 계획과 진행상황을 분리해서, 계획 문서가 진행 중에 계속 바뀌어 보이지 않게 합니다.
>
> **업데이트 규칙**: Claude Code는 TASK 완료를 PM이 확인("완료" 또는 "다음" 등 승인 발언)한 직후에만 체크박스를 바꿉니다. 스스로 판단해서 미리 체크하지 않습니다.
>
> `PM-` 코드 TASK는 Claude Code가 아닌 PM이 직접 수행하는 작업입니다(레포 루트 Git 명령, 외부 서비스 가입 등). 완료 여부를 PM이 직접 체크합니다.
